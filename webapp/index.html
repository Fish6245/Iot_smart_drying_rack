📖 Quy trình & Hướng dẫn Kỹ thuật

  • Cập nhật OTA 100% Không dây (Zero Hardware Touch): Hoàn toàn không cần chạm vào nút bấm phần cứng. Bạn chỉ cần nhấn "Kiểm tra bản cập nhật" rồi bấm "Update Firmware (OTA)" trên Web. Vi điều khiển ESP8266 sẽ tự động nhận lệnh qua Firebase, tải mã nguồn mới từ GitHub và tự khởi động lại.
  • Tự động kiểm tra khi cấp nguồn: Mỗi lần mạch khởi động lại, hệ thống sẽ tự đối chiếu file version.json trên GitHub để tự động đồng bộ bản mới nhất.
  • Khởi động lại từ xa (Soft Reset): Gửi cờ trigger_reset = true qua Firebase để khởi động lại mạch an toàn mà không cần rút nguồn điện vật lý.
  • Nút bấm cơ SW1 (D6 / GPIO 12): Dùng thuần túy để người dùng bấm đảo trạng thái đóng / mở sào nhanh tại chỗ khi đứng cạnh giàn phơi.
